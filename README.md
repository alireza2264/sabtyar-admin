# پنل مدیریت ثبت یار هوشمند

## نصب و راه‌اندازی

```bash
cd sabtyar-admin
npm install
npm run dev
```

سپس به آدرس `http://localhost:3000` بروید.

**رمز عبور پیش‌فرض:** `sabtyar1404`

برای تغییر رمز، متغیر محیطی `ADMIN_PASSWORD` را تنظیم کنید.

## استقرار روی Vercel

1. پروژه را به گیت‌هاب پوش کنید.
2. در Vercel یک پروژه جدید بسازید و این ریپو را انتخاب کنید.
3. دامنه را مثلاً `admin.sabtyarai.ir` تنظیم کنید.
4. متغیر محیطی `ADMIN_PASSWORD` را اضافه کنید.

## اتصال فرم‌های سایت اصلی

برای اینکه درخواست‌های سایت اصلی در این پنل ثبت شوند، در فرم‌های سایت این درخواست را بفرستید:

```js
await fetch("https://admin.sabtyarai.ir/api/leads", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    name: "نام کاربر",
    phone: "09xxxxxxxxx",
    email: "email@example.com", // اختیاری
    service: "ثبت شرکت",
    message: "پیام کاربر" // اختیاری
  })
});
```

## قابلیت‌ها

- داشبورد آماری
- مدیریت کامل درخواست‌ها (وضعیت، یادداشت، حذف)
- جستجو و فیلتر
- ویرایش محتوای سایت (نسخه نمایشی)
- ورود امن با کوکی

## توجه مهم

ذخیره‌سازی فعلی در حافظه سرور است (برای دمو). در هر ری‌استارت سرور داده‌ها پاک می‌شوند.
برای محیط واقعی باید به دیتابیس (مثل Vercel Postgres، Supabase یا Upstash Redis) متصل شود.
